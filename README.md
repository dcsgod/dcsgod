# Ravi Kumar

**Data Scientist · ML/GenAI Engineer · Decision Intelligence**

I build machine learning and AI systems that move from **data → models → reasoning → decisions**.

My work sits at the intersection of applied machine learning, LLM systems, quantitative methods, and data platforms. I am particularly interested in building systems that are not just intelligent, but **measurable, explainable, production-ready, and useful for real decisions**.

Currently working on enterprise AI/ML systems with **Databricks, Python, PyTorch, LangGraph, knowledge graphs, retrieval systems, forecasting, optimization, and agentic architectures**.
